# AZSOS UPDATE branch template

Put app installers/archives here for the in-app **Check updates** button.

Recommended layout:

```text
update.index.json
releases/
  AZSOS-Desktop-v0.3.3.exe
  AZSOS-Desktop-v0.3.3.zip
```

Default app update source:

```text
https://github.com/TheGreatAzizi/AzSoS/tree/UPDATE
```
