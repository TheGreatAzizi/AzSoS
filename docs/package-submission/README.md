# Submit AZSOS country packages

> Language: [English](submit-country-package.en.md) | [فارسی](submit-country-package.fa.md) | [العربية](submit-country-package.ar.md) | [Türkçe](submit-country-package.tr.md)

This section explains how community contributors can create `.azsos` packages for their own country, test them locally, and open a pull request so the maintainer can review and add them to the AZSOS package catalog.

## Available languages

- [English](submit-country-package.en.md)
- [فارسی](submit-country-package.fa.md)
- [العربية](submit-country-package.ar.md)
- [Türkçe](submit-country-package.tr.md)

## What this is for

Use these guides when you want to contribute a country-specific emergency/offline information pack, for example:

- first-aid basics
- emergency phone numbers
- local preparedness checklists
- offline business continuity notes
- digital safety basics
- verified public resources with proper attribution

Do **not** include private data, secrets, private keys, copyrighted material without permission, or unsafe instructions.
