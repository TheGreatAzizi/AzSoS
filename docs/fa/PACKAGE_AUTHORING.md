# ساخت بسته

> زبان: **فارسی** | [English](../en/PACKAGE_AUTHORING.md)


## فولدر محتوا

فولدر محتوا باید فایل‌های static داشته باشد:

```text
content/
  index.html
  pages/
    intro.html
  assets/
    image.webp
```

فایل ورودی معمولاً `content/index.html` است.

## نوشتن محتوا

محتوای خوب برای AZSOS این ویژگی‌ها را دارد:

- کوتاه است.
- منبع دارد.
- آفلاین‌پسند است.
- روی صفحه کوچک خوانا است.
- بدون لینک خارجی هم مفید است.

## پرهیز کن از

- اسکریپت ریموت
- فونت ریموت
- tracking pixel
- عکس‌های خیلی حجیم
- محتوای بدون attribution

## جستجو

packer می‌تواند index جستجوی SQLite FTS5 بسازد. عنوان صفحه‌ها را واضح بنویس چون نتایج جستجو معمولاً اول عنوان را نشان می‌دهند.

## متادیتا

تا حد امکان تاریخ review و منبع را داخل خود محتوا بنویس:

```text
Reviewed: 2026-05-03
Source: Example public guide
```
