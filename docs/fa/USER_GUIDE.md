# راهنمای کاربر

> زبان: **فارسی** | [English](../en/USER_GUIDE.md)


## AZSOS برای چیست؟

AZSOS کمک می‌کند محتوای مهم را وقتی اینترنت کند، فیلتر، ناپایدار یا کاملاً قطع است همچنان در دسترس داشته باشی. کاربر یک بار بسته را دانلود می‌کند، AZSOS آن را verify می‌کند و بعد محتوا آفلاین قابل استفاده می‌ماند.

## تب‌های اصلی

### Installed

این تب برای مدیریت بسته‌های نصب‌شده روی کامپیوتر است.

کارهایی که می‌توانی انجام بدهی:

- **Import `.azsos`**: اضافه کردن بسته از روی فایل.
- **Open package**: باز کردن صفحه اصلی بسته در مرورگر.
- **Search selected**: جستجو داخل یک بسته.
- **Search all**: جستجو در همه بسته‌های نصب‌شده.
- **Export package**: خروجی گرفتن از بسته نصب‌شده به فایل `.azsos`.
- **Delete package**: حذف بسته انتخاب‌شده از کتابخانه محلی.
- **Trust publisher**: trusted کردن fingerprint ناشر فقط روی همین دستگاه.

### Get content

این تب برای پیدا کردن بسته از سورس‌های آنلاین یا محلی است.

سورس‌های پشتیبانی‌شده:

- لینک GitHub branch/tree
- GitHub Releases
- لینک مستقیم `.azsos`
- فولدر محلی
- فایل registry با نام `packages.index.json`

روش پیشنهادی:

1. سورس پیش‌فرض را انتخاب کن.
2. روی **Fetch selected** بزن.
3. اگر لازم بود بسته را inspect کن.
4. یک یا چند بسته را انتخاب کن.
5. روی **Install selected** بزن.

### Share

این تب برای اشتراک‌گذاری بسته‌های نصب‌شده روی شبکه محلی است. وقتی فقط یک دستگاه بسته‌ها را دارد و بقیه دستگاه‌ها نزدیک هستند، این قابلیت کاربردی است.

روش استفاده:

1. دستگاه‌ها را به یک Wi-Fi، hotspot یا LAN وصل کن.
2. در تب Share روی **Start** بزن.
3. لینک محلی را کپی کن یا QR را نشان بده.
4. بقیه دستگاه‌ها لینک را باز می‌کنند و بسته‌ها را دانلود می‌کنند.

### Docs

تب Docs راهنمای AZSOS را داخل خود برنامه نشان می‌دهد. این بخش انگلیسی است و با حالت Markdown-style نمایش داده می‌شود.

## فایل‌ها کجا ذخیره می‌شوند؟

AZSOS داده‌های کاربر را اینجا ذخیره می‌کند:

```text
~/AZSOS/
```

فولدرهای مهم:

```text
~/AZSOS/library/    بسته‌های نصب‌شده
~/AZSOS/incoming/   دانلودهای موقت
~/AZSOS/updates/    فایل‌های آپدیت نرم‌افزار
~/AZSOS/config.json تنظیمات سورس‌های محتوا
```

## نکات استفاده امن

- تا حد امکان از بسته‌های ناشرهای شناخته‌شده استفاده کن.
- قبل از trust کردن ناشر، fingerprint را از یک مسیر قابل‌اعتماد بررسی کن.
- کشف بسته به معنی اعتماد نیست.
- اگر می‌خواهی بسته‌ها را بعداً به دیگران بدهی، export آن‌ها را جای امن نگه دار.
