# راهنمای داخل برنامه

> زبان: **فارسی** | [English](../en/IN_APP_MANUAL.md)


راهنمای داخل خود نرم‌افزار AZSOS فعلاً انگلیسی است و در تب **Docs** نمایش داده می‌شود. این صفحه نسخه فارسی توضیحی برای همان راهنماست تا مستندات گیت‌هاب دو زبانه و جدا باقی بماند.

## چرا داخل برنامه انگلیسی است؟

در نسخه فعلی، UI و راهنمای داخل برنامه برای انتشار عمومی گیت‌هاب انگلیسی نگه داشته شده‌اند تا کاربران غیر فارسی‌زبان هم بتوانند از پروژه استفاده کنند. مستندات گیت‌هاب اما دو نسخه جدا دارد: فارسی و انگلیسی.

## چیزهایی که در تب Docs توضیح داده می‌شود

- What AZSOS does
- What a `.azsos` file is
- Installed packages
- Get content
- Local Share
- Software updates
- Security model

- Common errors
